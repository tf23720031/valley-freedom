# 縱谷自由行動所｜VALLEY FREEDOM

以花蓮瑞穗木日光文旦驛站及花東縱谷為場域的地方微體驗、自由旅程與青年協作展示原型。網站內容、價格、預約、任務與營運數據皆為示意資料。

## 本機啟動

```bash
npm ci
npm run dev
```

Vite 預設會在終端顯示本機網址。切換頁面上方的「展示視角」，可查看旅客、青年及業者工作區。旅客可從體驗詳情送出模擬預約；旅程草稿不會建立預約。業者可新增體驗、調整場次名額、確認或取消預約、審核青年任務，並在「地方體驗共創」完成草案至正式上架流程。

## 示範資料

所有資料儲存在目前瀏覽器的 `localStorage`。不同頁面和同源分頁會共用及更新資料；LocalStorage 與 `storage` 事件不提供跨分頁並行交易保證，也不代表多人雲端同步。頁首「重置資料」會先再次確認，再還原初始示範資料。

預約待確認及已確認狀態會占用場次名額；取消紀錄會保存原因、操作來源與時間，並釋出名額。已完成預約不可取消。共創正式體驗會保存來源草案 ID，可追溯資源、試辦、回饋與修改記錄。

## 檢查與測試

```bash
npm run typecheck
npm test -- --run
npm run build
npm run test:e2e
```

Vitest 與 React Testing Library 驗證領域規則及互動元件；Playwright 使用本機 Google Chrome，在桌面與手機尺寸驗證主要流程及頁面寬度。Playwright 桌面瀏覽器需安裝 Google Chrome。

## 限制

原型沒有真實登入、角色權限、金流、地圖 API、後端資料庫、通知或多人即時同步。取消和預約等操作只會更動目前瀏覽器的示範狀態；實際營運前需接上安全的後端交易與身分驗證。
