# 縱谷自由行動所（VALLEY FREEDOM）互動旅行品牌改版規格

日期：2026-10-16
狀態：依使用者確認之新版 Brief 更新

## 目標

以現有 React 19、TypeScript、Vite 專案為基礎，將 VALLEY FREEDOM 改造成一個沉浸、可操作、內容完整的花東自由旅行品牌原型。核心任務是讓旅客自行安排旅程，並在行程空白處直接尋找合適的在地旅伴。保留所有既有頁面、路由、資料及旅客、旅伴、業者、青年流程；完成後更新既有公開 Sites 專案，維持現有網址和公開權限。

## 範圍與限制

- 本次只修改前端；沿用 React Router、集中式 store、LocalStorage 和既有示意資料，不建立後端、登入、付款、地圖 API 或真實媒合。
- 必須保留既有路由、預約/取消、行程草稿、旅伴服務需求、業者工作台、青年工作台、地方體驗共創和 404 頁面。
- 所有未確認人物、資格、價格、場域、合作、交通時間與服務資訊，均明確標示為「示意」、「待查證」或「非場域實景」；不得把構想寫成已存在的服務。
- 主要驗收視窗：1440/1920px、768/1024px、390/430px；不允許橫向溢出、裁切文字、內層捲軸或無作用控制項。
- 支援鍵盤焦點、語意化標記、清楚的狀態回饋與 `prefers-reduced-motion`。低效能或不支援 WebGL 時須可用靜態圖片完成任務。
- 使用者已明確授權連續執行 Phase 1–7 並更新既有正式網站；各階段不再等待確認。

## 日本實驗性網站參考檢視（2026-10-16）

以瀏覽器實際檢視桌機 1440×900 與手機 390×844 首屏/滾動狀態；僅借鑑版面和互動方法，不複製素材、文案、程式或品牌元素。

- HEARTS（`https://hearts.co.jp/`）：桌機首屏是置於圓角白色導覽之下的大幅紀實影像，底部以山脊剪影接入深綠內容；向下後導覽固定、首頁影像退出、直排新聞清單接續。手機把照片改為窄直幅、保留同一影像焦點與頂部精簡導覽，內容自然向下流動。借用其影像先行和清楚的首尾銜接，不仿其山形遮罩或企業色。
- MORE THAN（`https://morethan-kobe.jp/`）：首屏先留大片白色負空間，再以全幅人物攝影和錯位的大型日文標題疊合；往下是大字介紹和圖片/文字左右交錯的編輯版面。手機將主影像置中直幅呈現，文字回到正常閱讀流。Marquee 段以使用者提供的截圖作構圖參考：多列超大混合字重文字、行間穿插尺寸不一的直式照片、自然裁出視窗；滾輪進度驅動位移，不使用自動循環。
- VESSEL（`https://vessel-for.jp/`）：桌機首屏左右兩張滿版人物照片分屏，下緣用大弧面色塊和沿弧排列文字連接，往下切成單色底、左右欄標題/說明。手機首屏改為單張直幅照片，弧面及文字仍保留為品牌轉場；未把整頁強制做成輪播。借用一段弧形圖像導覽/照片牆作四區探索，不把弧形套用到表單與工作台。
- URBANEX SHIFT（`https://ogud.co.jp/urbanex/shift/`）：桌機先呈現深藍滿版載入色場，再進入白底超大字、細密橫線與歷史視覺元素；滾動以分段的線條遮罩揭示字形/內容，區塊以橫向細帶分隔。手機檢視時停留在百分比載入畫面，未取得穩定完成後畫面，因此只採用桌機可觀察到的線條遮罩和段落銜接方法，不推測其手機效果。

### 現站差距

桌機現站首屏是滿版背景圖，上方疊置「旅程，由你決定。」、長副文案與雙入口；屬於一般 Hero 對齊構圖，缺少照片作為獨立畫幅的擴張、文字分層位移與明確的滾動控制。中段仍有程序化地景及「一條山與海之間的路／把縱谷，慢慢走過」的說明語氣；缺少大字與地方攝影交錯的純視覺轉場。四區首頁是等寬 2×2 圖卡，與參考站的弧形／錯位圖像編排不同。手機現有區塊多為桌機版堆疊縮小，缺少獨立的字體/影像比例與節奏。

## 設計系統

### 藝術方向

設計成花東影像編輯刊物，融入日本實驗性網站的圖像/字體碰撞：Noto Sans TC Black 超大中文字、Archivo Black 或 Space Grotesk 英文字、不同基線和速度的錯位排版、大幅地方影像及可反向的滾輪敘事。滿版視覺後必須順暢回到清楚的導航、可用表單與實用旅程資訊。避免旅行電商式搜尋面板、SaaS 統計卡、制式 AI landing page、抽象重複文案、過量裝飾和無關動畫。

### 核心 tokens

- Forest：`#243E32`
- Cream：`#F5F2E9`
- Sage：`#A7B7A1`
- Sand：`#CFB69A`
- Ink：`#292D29`
- 中文 display：Noto Sans TC，900；系統備援維持可讀粗體。
- 英文 display：Space Grotesk 或 Archivo Black；內文採清晰無襯線。
- Hero：桌面 display 使用 `clamp(76px, 12vw, 190px)`，手機 `clamp(54px, 16vw, 86px)`；marquee 行文字使用 `clamp(64px, 11vw, 170px)`；資訊章節標題 36–76px；內文 16–18px。

### 版面原則

桌面主視覺以左對齊、跨格圖片畫幅和位移文字組成；中段 marquee 三行不同速度的水平視覺文字及穿插直式照片；四區以單段弧形 editorial gallery 進入個別地區。手機採獨立直向構圖、水平溢位由容器裁切而非頁面溢出，Marquee 降低字級並將 scrub 換成短距離原生滾動，取消長時間 pinning 和高負載 3D。旅伴、行程、預約和工作台使用不同版面，以操作清晰優先。

## 資訊架構與頁面內容

現有路由：`/`、`/experiences`、`/experiences/:experienceId`、`/companions`、`/companion`、`/explore`、`/explore/:regionId`、`/places/:placeId`、`/itinerary`、`/bookings`、`/muri-sunshine`、`/youth`、`/youth/tasks/:taskId`、`/operator`、`/operator/experiences`、`/operator/bookings`、`/operator/tasks`、`/co-create` 和 `*`。改版不得移除或改變其既有用途。

- 首頁：照片由偏置矩形畫幅擴至滿版，主文案「花東，自己玩。」副文案「不跟團、不趕行程。想找人同行，也可以。」；GSAP ScrollTrigger pin/scrub 同步控制照片 scale/clip 與不同方向的標題位移，兩個入口做低調浮層。其後以純白/米白、三行混合中英巨大文字和不等尺寸照片建成 scroll-scrub Marquee，取代舊山海概念區。再以一段弧形照片導覽呈現四區，接續地方體驗、旅伴、行程空檔示意和 CTA；每段採不同視覺節奏。
- 四區探索：太魯閣、東海岸台 11 線、花東縱谷台 9 線、臺東南迴各具影像與地方主題。每區顯示可查證事實/候選場域、建議停留時間與交通規劃提示（皆標示為參考或示意）、地方特色、旅行節奏、來源/查核狀態及加入行程入口。地圖式插圖如出現須標示為概念示意，不充作導航。
- 場域詳情：保留現有公開來源、查核狀態、預約連結、合作狀態與加入行程/附近找旅伴入口；資料不足時清楚呈現待查證。
- 行程：保留每日編輯、增加/修改/刪除/排序、預算與衝突提示、收藏場域加入草稿；依時間排序相鄰活動並計算可用空檔，顯示起訖、空檔長度與地點脈絡。每個空檔提供「找在地旅伴」，以日期、空檔開始時間、可用時長、地區、旅程 ID 帶入搜尋頁；不產生虛構 ETA、不自動建立預約。
- 旅伴搜尋/工作台：搜尋需求可由行程參數預填；呈現人物故事、語言、興趣、服務範圍、擅長事項、服務限制、示意費用、可詢問時段與需求送出/回覆流程。人物和資格皆為示意。
- 體驗、預約、業者、青年、共創及 404：保留原本資訊與互動，整合字體、色彩、焦點、回饋和手機閱讀層次。管理頁優先可讀性，不增加持續執行的重型 3D。

## 動畫與 3D 架構

- Three.js、React Three Fiber：只在首頁局部地景敘事中保留單一延遲載入 Canvas；不得讓初始 Hero 等待 WebGL。首屏使用本地照片畫幅並由 GSAP 控制擴張；可於後續地景使用程序化分層山脈/海線，註明非精確地圖。
- Canvas 有靜態本機照片 fallback、低 DPR/低負載設定、WebGL 錯誤回退；非首頁路由不建立 Canvas。
- GSAP 與 ScrollTrigger：獨立 motion 模組實作 Hero 擴張/文字位移、Marquee 多列 scrub、區域弧形畫廊、必要的 clip-path reveal/SVG 路線與短頁面切換。所有時間軸跟隨真實滾動並可反向/快速滾動；context cleanup，窄螢幕縮短或取消 pin，減少動態偏好改用靜態版面。
- 使用原生捲動，不導入 scroll-jacking 或全站強制平滑滾輪。動效只服務地景移動、區域關係和資訊揭露。

## 實作階段與驗收

1. **規格與參考審視**：已實際檢視四站，補齊站點差異、可借方法及現站差距；更新規格與實作計畫後以現站截圖作 baseline。驗收：桌機/手機參考狀態與限制寫入文件。
2. **HEARTS 式首頁 Hero**：Hero 換為偏置照片畫幅＋超大「花東，自己玩。」；desktop ScrollTrigger pin/scrub 控制圖片擴張與標題/副文案分速位移；手機用直幅圖片和短距離原生滾動。驗收：兩入口仍可操作，圖片載入不跳版，動畫可逆。
3. **MORE THAN 式全幅 Typography Marquee**：刪除舊山海概念展示區，以白/米白三行大型多字重文字、尺寸/位置不同的地方照片與反向 scrub 取代。驗收：不是自動 marquee，桌面文字/照片隨進度移動，手機獨立堆疊且無頁面橫向溢出。
4. **VESSEL 式四區弧形探索與全站敘事**：四區探索入口改成僅此一段的弧形影像導覽；地區/人物使用錯位編輯構圖，行程保留易用時間軸。以 SHIFT 的細線/遮罩段落銜接輔助，不複製固定同款動畫。驗收：路由、資訊、加入行程皆保留。
5. **資訊與文案精修**：逐頁檢查交通、停留、安排、場域內容、旅伴服務與預約流程；精簡禁用的抽象重複語，示意資訊明確標籤。驗收：核心旅程和缺失資訊完整，Mock 與已查資訊容易區分。
6. **核心流程與相容性回歸**：確認空白時段辨識、日期/時間/地區帶入搜尋、行程編輯、媒合、預約及工作台；修動畫 cleanup、reduced motion 和載入 fallback。驗收：原有資料和路由行為不退化。
7. **四尺寸視覺 QA 與正式發佈**：以 1440×900、1920×1080、390×844、430×932 截圖比較；修溢出、裁字、CLS、焦點、動效和手機視覺後跑完整測試/build，更新同一正式 Sites 版本。
